# Online Retail Customer & Revenue Analytics

### Driving Business Growth Through Data-Driven Insights

## Project Overview

This project analyzes online retail transactions to identify revenue trends, customer purchasing behaviour, product performance and business growth opportunities.

It combines Python-based data analytics, Machine Learning and Power BI to transform retail transaction data into actionable business insights.

## Dataset

**Source:** [UCI Online Retail II Dataset](https://archive.ics.uci.edu/dataset/502/online+retail+ii)

The cleaned dataset used in this project covers December 1, 2009 to December 9, 2010.

- Cleaned records: 400,916
- Total customers: 4,312
- Total products: 4,017
- Total orders: 19,213

## Machine Learning

### K-Means Clustering

Used to segment customers based on Recency, Frequency, Monetary Value and Average Order Value.

- Number of clusters: 4
- Silhouette Score: 0.2699

### Random Forest Classification

Used to predict whether a customer will make another purchase within the next 90 days.

| Metric | Score |
|---|---:|
| Accuracy | 83.26% |
| Precision | 35.38% |
| Recall | 43.81% |
| F1 Score | 39.15% |
| ROC-AUC | 76.76% |
